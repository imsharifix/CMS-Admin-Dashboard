# 🚀 React Admin Dashboard

A modern, responsive and professional admin dashboard built with **React**.  
This project focuses on clean UI design, reusable components, data visualization, and scalable frontend architecture.

## 📌 Overview

React Admin Dashboard is a frontend dashboard application designed for managing users, products, and business data.

The project provides a clean and modern interface with interactive charts, reusable components, and responsive layouts suitable for admin panels and CMS systems.


## ✨ Features

### 📊 Dashboard
- Sales analytics overview
- Interactive charts using Recharts
- Latest transactions section
- New members overview
- Responsive dashboard layout


### 👥 User Management
- Users list page
- Create new user page
- User information display
- Reusable table components


### 📦 Product Management
- Product list
- Product details page
- Product statistics
- Product sales chart
- Custom select components
- Product editing interface


### 🎨 UI / UX
- Modern card-based design
- Responsive layout
- Custom components
- Smooth hover animations
- Clean typography
- Professional admin panel style

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/imsharifix/react-admin-dashboard.git
```

Go to project directory:

```bash
cd react-admin-dashboard
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
